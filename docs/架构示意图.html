模型输出的信任管线 —— 每一次 LLM 调用都要走完全部闸门

路线核心刻意不用 LLM

  • 六维加权评分、有向 Dijkstra 最短路、≤12 厅 Held-Karp 子集 DP（>12 厅贪心 + 2-opt）全部是确定性算法。
  • LLM 只提供两个输入：InterestProfile 兴趣标签 + 查询向量，之后的决策可复现、可回归测试（199 项测试）、零 token 成本。
  • 精确最优的边界写进返回值（optimality_scope）：限于既定单厅 Top-K、预计算最短通路与尾部剔除规则之内。

模型输出一律不可信

  • 严格 JSON 解析：拒绝未知/缺失字段、重复键、代码围栏外文本、SDK 包装。
  • 不可变数据类（frozen + slots）二次构造校验：引用范围、顺序、数量。
  • 两个 Reviewer 独立成调，不复用 Composer 的判断；approved=true 时 issues 必须为空，无默认批准。
  • 任一环节失败 → 不写入会话状态（原子性）；算子每次外部调用后还会比对会话快照防过期提交。
